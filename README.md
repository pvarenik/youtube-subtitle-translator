# yt-subtitle-translator

Browser extension that translates YouTube subtitle words on hover.

Click any word in YouTube subtitles to see its translation in a tooltip.

## Providers

- Google Translate (free)
- DeepL Free (free, API key required)
- DeepL Pro (paid, API key required)
- LibreTranslate (self-hosted or public)
- Custom endpoint

## Install

Requires **Firefox 78+**.

1. Open `about:debugging` in Firefox.
2. Click **This Firefox** → **Load Temporary Add-on**.
3. Select `manifest.json` in this directory.

## Configure

Click the extension icon to set source/target languages, provider, and API key.
